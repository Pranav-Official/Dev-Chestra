# P2 acceptance fixtures

Deterministic inputs for `tools/p2-smoke`. They use only the fake agent and
shell nodes; no live provider, model or credential is involved.

| File | Purpose |
|---|---|
| `workflows/p2-basic.json` | `start -> fake agent -> shell -> end`; the run under test. |
| `scripts/basic.json` | Immediate valid submission (`P2 acceptance summary`). |
| `scripts/slow.json` | Delays five seconds, so a tab can close/reconnect mid-run. |
| `scripts/browser.json` | Delays eight seconds for the tab-close/reopen scenario. |
| `scripts/hold.json` | Long hold for API/security tests that then cancel. |
| `scripts/html.json` | Submits `<img onerror>` / `<script>` markup that must render as text. |

The `p2-many` backlog workflow is generated by `tools/p2-smoke/src/fixtures.ts`
(75 real shell nodes, roughly ten durable events each) so the repository does
not carry a thousand-line JSON file. The P2 driver writes everything into a
fresh `mkdtemp` project and never touches the repository or `~/.devchestra`.
